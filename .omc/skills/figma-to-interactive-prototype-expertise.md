# Figma 노드 → 인터랙티브 HTML 프로토타입

## The Insight
Figma MCP로 노드 구조를 읽으면 **상태별 UI 변형(Default/Active/Disabled 등)과 실제 텍스트 값**을 정확히 파악할 수 있다. 스크린샷만으로는 놓치기 쉬운 상태 전환 규칙, 조건부 표시 요소, 인터랙션 힌트(annotation)까지 한 번에 추출 가능하다.

## Why This Matters
- 스크린샷만 보고 구현하면 상태별 디자인을 놓치거나, 잘못된 스타일(레거시 vs 모던)을 가정하게 됨
- Figma에서 annotation이나 라벨로 명시된 인터랙션("클릭 시 모달 열림", "설정 후 사용 중으로 변경됨")을 코드로 반영해야 함
- 한 섹션 안에 여러 상태 프레임이 나란히 있으면 그것이 같은 컴포넌트의 상태 변형임

## Recognition Pattern
- 사용자가 Figma URL 또는 채널을 제공하고 "이 디자인대로 구현해줘"라고 할 때
- 하나의 Section 안에 "Default", "Active", "미사용 상태" 같은 라벨이 붙은 프레임이 여럿 있을 때
- 텍스트 노드의 characters 값이 실제 UI에 표시될 콘텐츠일 때

## The Approach

### 1. 노드 탐색 순서
1. `get_document_info` → 페이지 구조와 최상위 섹션 파악
2. `get_node_info(sectionId)` → 섹션 내 children에서 상태별 프레임 식별
3. children의 `name` 필드에서 상태 라벨 추출 (e.g., "Default", "Active")
4. 각 프레임의 텍스트 노드에서 `characters` 값 추출

### 2. 상태 변형 매핑
```
Figma Section "🩵크레딧 자동 충전"
├── Frame "Default" (미사용 상태)
│   └── 체크박스 "사용" (unchecked)
├── Frame "Active" (사용 중)
│   └── 체크박스 "사용" (checked)
│   └── 텍스트 "100 크레딧 남았을 때 10만원씩 자동 충전"
│   └── 버튼 "설정"
```
→ HTML에서 하나의 컴포넌트로 구현하고, JS로 상태 전환

### 3. Annotation 활용
- `INSTANCE` 타입 노드 중 annotation 스타일(작은 폰트, 배경색 라벨)은 **인터랙션 힌트**
- e.g., "클릭 시 자동 충전 설정 모달 열림" → onclick 핸들러로 구현
- e.g., "클릭 시 자동 충전 기능 비활성" → 체크 해제 시 상태 변경

### 4. 스크린샷 먼저 확인
- Figma 노드 데이터만으로는 색상(`#NaN` 등)이나 시각적 뉘앙스를 놓칠 수 있음
- **반드시 실제 화면 스크린샷과 대조**하여 스타일(배경, 보더, 간격)을 확인
- 레거시/모던 스타일을 가정하지 말고, 스크린샷 기반으로 판단

### 5. 설정값 영속성
- 한번 설정된 값은 체크 해제해도 계속 표시 (Figma에서 Active 상태에 설정값이 보이면)
- 상태 전환 시 설정값을 변수에 저장하고, UI 표시와 체크박스 상태를 분리 관리
